### Приложение "EnglishCard" позволяет вам изучать английский язык, выбирая правильный перевод русских слов английскими словами. Вы можете пополнять изначальный набор слов своими, удалять свои слова, отслеживать свою статистику правильных ответов, а также можете посмотреть схему базы данных (где хранятся данные этого приложения).

#### Приложение состоит главным образом из трёх модулей: 1) "db_scripts.py", где описаны функции соединения и работы с базой данных, а также начальный общий список пар слов на русском и английском языках; 2) "st_scripts.py", где описаны функции, созданные на основе библиотеки STREAMLIT и отвечающие за отображение в окне браузера элементов приложения и за связь этих элементов с функциями модуля "db_scripts.py" и с действиями пользователя; 3) "main.py", где происходит создание и запуск приложения. Цвета и шрифт приложения прописаны в файле "config.toml" папки ".streamlit".

### Описание модуля "db_scripts.py":

#### Функция "get_db_connection()" отвечает за связь приложения с базой данных. Параметры соединения находятся в дополнительном файле ".env" (как пример показан файл "example.env"), а также в самой функции как пред-определённые параметры, используемые в отсутствии параметров в файле ".env".

#### Функция "init_database()" создаёт базу данных из четырёх таблиц ("пользователи", "общие слова", "персональные слова", "персональная статистика"), а также заполняет таблицу "общие слова" словами из начального списка. Чтобы всё это не выполнялось заново при каждом взаимодействии пользователя с приложением, для этой функции используется декоратор "@st.cache_data".

#### Функция "login_user(username)" принимает строку (имя пользователя), соединяется с базой данных и узнаёт, имеется ли такое имя пользователя в таблице "пользователи". Если имеется, то функция сразу возвращает номер пользователя. Если нет, то имя пользователя заносится в таблицу, а затем функция тоже возвращает номер пользователя.

#### Функция "get_user_words(user_id)" принимает число (номер пользователя), соединяется с базой данных, запрашивает слова из таблицы "общие слова" и из таблицы "персональные слова" (этого пользователя), если таковая имеется, объединяет данные в список словарей этих пар слов и возвращает этот список. Для каждой пары слов в их словаре в ключе "тип" указано значение "общий" или "персональный" в зависимости от того, из какой таблицы была взята эта пара слов.

#### Функция "add_personal_word(user_id, russian_word, english_word)" принимает число и две строки (номер пользователя, русское слово, английское слово) и переводит слова в нижний регистр (чтобы избежать дублирования слов в разных регистрах). Затем происходит соединение с базой данных, и если этой пары слов нет в общем списке слов и в персональном списке слов этого пользователя, то слова заносятся в персональный список слов этого пользователя, и функция возвращает значение True. В обратном случае функция возвращает значение False.

#### Функция "delete_personal_word(user_id, word_id)" принимает два числа (номер пользователя и номер слова), соединяется с базой данных и делает попытку удаления этого слова у этого пользователя из таблицы "персональные слова". Если такое слово было удалено, то из таблицы "персональная статистика" удаляется статистика по этому слову у этого пользователя, и функция возвращает значение True. В обратном случае функция возвращает значение False.

#### Функция "update_stats(user_id, word_id, word_type, is_correct)" принимает два числа, строку и Булево значение (номер пользователя, номер слова, тип слова, True или False), соединяется с базой данных и изменяет данные в таблице "персональная статистика" для этого слова у этого пользователя (или создаёт соответствующие данные, если такого слова у этого пользователя в таблице "персональная статистика" ещё не было). Если у параметра is_correct значение True, числа в полях "правильные ответы" и "все попытки" увеличиваются на единицу. Если у параметра is_correct значение True, изменяется число (увеличивается на единицу) только в поле "все попытки".

#### Функция "get_statistics(user_id)" принимает число (номер пользователя), соединяется с базой данных и запрашивает из таблицы "персональная статистика" количество всех слов, сумму правильных ответов по всем словам, сумму всех попыток по всем словам и время самой недавней попытки ответа для этого пользователя. Функция возвращает словарь с этими данными и номером пользователя. Если данных в таблице "персональная статистика" для этого пользователя ещё нет, функция возвращает такой же по составу словарь, но с нулями для ключей "количество всех слов", "сумма правильных ответов" и "сумма всех попыток", а также со значением None для ключа "время самой недавней попытки".

#### Функция "generate_options(all_words)" принимает список словарей (со словами конкретного пользователя), с помощью библиотеки RANDOM выбирает случайное русское слово из этого списка и три случайных неправильных английских ответов из этого же списка, и возвращает список значений (номер этой выбранного слова, само слово, его английский перевод, тип слова и список, состоящий из правильного английского перевода и трёх случайных неправильных ответов, вдобавок перетасованный с помощью библиотеки RANDOM).

### Описание модуля "st_scripts.py":

#### Функция "render_sidebar()" осуществляет боковую панель приложения. При запуске приложения в боковой панели появляется кнопка "Войти", при нажатии которой появляется поле ввода имени пользователя. После введения имени пользователя и нажатии кнопки "Подтвердить" (или "Ввод" на клавиатуре) в боковой панели появляется надпись с именем пользователя и кнопку выхода из приложения "Выйти", а в основном пространстве приложения появляются инструменты изучения английского языка. С помощью функции "login_user(username)" имя пользователя заносится в таблицу "пользователи" базы данных.

#### Функция "render_study_tab()" осуществляет инструмент изучения английского языка "Изучение", где с помощью функций "get_user_words(user_id)", "generate_options(all_words)" и "update_stats(user_id, word_id, word_type, is_correct)" можно выбирать варианты перевода русских слов, нажимая соответствующие кнопки и кнопку "Слкдующее слово", а после каждого нажатия кнопок с вариантами перевода происходит изменение статистики пользователя в таблице "персональная статистика" базы данных.

#### Функция "render_add_word_tab()" осуществляет инструмент изучения английского языка "Добавить слово", где с помощью функций "add_personal_word(user_id, russian_word, english_word)" и "get_user_words(user_id)" можно ввести русское слово и его перевод в соответствующие поля, и добавить эту пару в изучаемые слова (таблицу "персональные слова") этого пользователя, нажав кнопку "Добавить в базу данных". При этом появляется сообщение об общем количестве (общие слова плюс персональные слова) изучаемых слов на данный момент.

#### Функция "render_delete_word_tab()" осуществляет инструмент изучения английского языка "Удалить слово", где с помощью функций "get_user_words(user_id)" и "delete_personal_word(user_id, word_id)" можно удалить русское слово из изучаемых слов (таблицы "персональные слова") этого пользователя, выбрав его из выпадающего списка русских слов и нажав на кнопку "Удалить слово из базы данных".

#### Функция "render_statistics_tab()" осуществляет инструмент изучения английского языка "Статистика", где с помощью функции "get_statistics(user_id)" отображаются количество изученных слов, количество попыток, количество правильных ответов, процент правильных ответов и время самой недавней попытки.

#### Функция "render_schema()" при нажатии кнопки "Показать схему базы данных" внизу окна приложения выводит изображение схемы базы данных, которое исчезает при нажатии кнопки "Скрыть схему базы данных"

### Описание модуля "main.py":

#### Создание и запуск приложения происходит с помощью функций "set_page_config(page_title="EnglishCard - Изучение английского", page_icon="📚", layout="wide")" и "title("📚 Привет, давайте попрактикуемся в английском языке!")" библиотеки STREAMLIT. Осуществляется соединение с базой данных и её первоначальное заполнение. Пока имя пользователя не введено, отображается первоначальная инструкция по использованию приложения. После введения имени пользователя появляются инструменты изучения английского языка (кликабельные контейнеры "tab") с помощью функции tabs() библиотеки STREAMLIT. Внутри этих контейнеров работают функции "render_study_tab()", "render_add_word_tab()", "render_delete_word_tab()" и "render_statistics_tab()". Функция "render_schema()" выодит (и скрывает) изображение схемы базы данных.
